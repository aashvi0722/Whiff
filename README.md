# Whiff

**Know when the smoke is coming.**

Whiff shows where India's smoke is coming from, when it will reach you, and how to plan your day around it, in Hindi and English.
Built for the WeMakeDevs x AWS Environmental Hacks (Bharat Builds Tour, Air track), Oct 8 to 11, 2026.

> Work in progress. The full README (screenshots, features, tech, how to run, credits) is written by Person B at S5.
